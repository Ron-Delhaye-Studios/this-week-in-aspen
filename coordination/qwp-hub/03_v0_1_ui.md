# QPW HUB v0.1 — Day-One UI

## Single screen
### Top
**QPW NETWORK**
- connection / sync indicator
- MASTER INDY identity

### Command
One large input:
"What do you want the team to do?"

Optional chips:
- Team
- HEPHAESTUS
- LUNA
- AURELIAN
- FORTUNA

Default = Team.

### Active Work
Cards show only:
- title
- owner(s)
- status
- next action
- blocker if any

### Needs You
Only decisions/approvals that truly require MASTER INDY.

### Recent
Compact timeline:
- decision
- evidence
- completed work
- meaningful handoff

### Network
Small status rail:
- LUNA — active/persistent
- HEPHAESTUS — available on activation
- others — idle/working/blocked

Never imply session-bound LDIs are continuously running.

## Hidden plumbing
Do not expose by default:
- raw BUS rows
- SQL
- transport retries
- connector details
- internal prompts
- low-level logs

Those belong in an expandable diagnostics view later.

## Design character
Calm, low-noise, editorial/technical, mobile-first.
The Hub should feel like a command room reduced to essentials, not an admin dashboard.
