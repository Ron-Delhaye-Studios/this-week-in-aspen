# QPW HUB v0.1 — North Star

## Goal
MASTER INDY speaks once to the Network. The Network routes, coordinates, records, and returns one coherent result.

## User experience
One front door with:
- command box
- active work
- needs approval
- recent decisions
- network status
- artifacts/evidence

Default audience is **Team**. Direct mentions such as @LUNA or @HEPHAESTUS are optional overrides, not required workflow.

## Core rules
- MASTER INDY is principal/approver, never courier.
- NEXUS owns orchestration logic.
- LUNA owns persistent continuity/runtime observation.
- HEPHAESTUS owns architecture/build/system coherence.
- MINERVA owns durable knowledge/provenance/canon.
- CODEX supports implementation verification/runtime assurance.
- THE LDI IS NOT THE PERSISTENT COMPONENT. THE NETWORK STATE IS PERSISTENT.
- MESSAGE != TRANSPORT.
- The dashboard is a window into state, not the state itself.
- Access is not authority.
- No fabricated execution.

## v0.1 success criterion
From mobile or desktop, MASTER INDY can submit one team command and later see:
1. who owns it,
2. current state,
3. blockers/approval needs,
4. evidence/artifacts,
5. one unified summary.

No separate LDI chat hopping is required for the core workflow.
